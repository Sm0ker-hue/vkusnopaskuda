# Правила и инварианты проекта «ВкусноПаскуда!» (FoodTech PWA)

## 1. Геолокация и гео-поиск
- **Приоритет реальной геолокации:** Определение координат пользователя строится на реальном GPS-датчике устройства (`navigator.geolocation` с высокой точностью `enableHighAccuracy: true`), а не на статических заглушках.
- **Целевой регион — весь город Пльзень (Plzeň, ČR):** Поиск магазинов, расчёт дистанций и навигация охватывают все доступные филиалы по всему городу без ограничения отдельными районами или фиксированным числом точек.
- **Запрет на Прагу:** Запрещено использовать координаты и филиалы Праги в качестве значений по умолчанию или fallback-данных.

## 2. База магазинов и филиалов
- База данных филиалов должна поддерживать полное покрытие всех физических супермаркетов Пльзеня (Lidl, Albert, Billa, Kaufland, Penny, Tesco, Globus, Coop, Norma).
- Дистанция рассчитывается математически (Haversine + пешеходный коэффициент) от фактической GPS-точки устройства пользователя до каждого магазина в городе.

## 3. Семантика сопоставления ингредиентов (Matcher Guardrails)
- При сопоставлении ингредиентов из рецептов с реальными товарами в каталогах магазинов строго соблюдать несовместимость категорий:
  - Межвидовые конфликты мяса (говядина, курица, свинина, рыба, дичь) возвращают score `0.00`.
  - Растительный протеин (тофу, соя, бобовые) и продукты животного происхождения возвращают score `0.00`.
  - Растительный протеин и молочные продукты возвращают score `0.00`.

## 4. Синхронизация зависимостей и CI/CD
- При добавлении любых асинхронных библиотек, моделей или типов Pydantic обязательно фиксировать их в `backend/requirements.txt`:
  - `greenlet` — обязателен для SQLAlchemy asyncpg в среде Linux / GitHub Actions.
  - `email-validator` — обязателен для валидации `EmailStr`.
- Перед пушем в репозиторий проверять успешное прохождение локальных тестов и линтеров: `verify_all_features.py`, `npm run lint`, `npm run build`.

## 5. Архитектура и стабильность интерфейса PWA
- Элементы навигации (`BottomNav`) могут изменяться и дополняться, но обязаны использовать стабильные уникальные строковые ключи для предотвращения дублирования вкладок при ререндере.
- Контекстные экраны (ингредиенты конкретного рецепта, корзина), для которых ещё не выбран рецепт, отображаются в отключённом состоянии (`isDisabled`), предотвращая неожиданные сбросы навигации на главную страницу.
